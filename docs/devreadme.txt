First I'd recommend you to read the GPL, before using the Xfrog source code. The GPL is located at the "gnu.txt" file.

To compile the Xfrog source code you'll need:

    - Visual C++ 6.0 (i've not tested with the 5.0 version)
    - DJGPP v2.02    - for compile the CFS packer
    - DirectX 7.0+   - www.microsoft.com/directx
    - zlib v1.13     - ftp://ftp.cdrom.com/pub/infozip/zlib/zlib.html
    - NASM v0.98     - http://www.web-sites.co.uk/nasm/
    
The zlib libraries and headers need to be on your compiler enviorment path. The NASM executable, must be named as "nasm.exe", and must be into a path directory.
